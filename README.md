# PathPilot AI

AI-enabled adaptive learning platform designed for competency assessment, skill-gap detection, personalized learning pathways, quiz generation, and continuous progress tracking.

## Repository Structure

- `documentation/` — project explanation, architecture, features, and SIH problem context.
- `source-code/` — application source code.

## Project Focus

PathPilot AI is being developed around the Smart India Hackathon learning-platform problem statement, with planned integration concepts for the iGOT Karmayogi ecosystem.
