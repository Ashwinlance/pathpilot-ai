# PathPilot AI — Project Overview

## Overview
PathPilot AI is an AI-enabled adaptive learning platform focused on identifying competency gaps and recommending personalized learning pathways.

## Core Capabilities
- Competency assessment
- Skill-gap detection
- Personalized learning recommendations
- AI learning assistant
- Quiz and MCQ generation from learning materials
- Continuous assessment and progress tracking
- Planned integration concepts with the iGOT Karmayogi ecosystem

## Repository Organization
This folder contains project documentation and explanations. The `source-code/` folder is reserved for the application implementation.
